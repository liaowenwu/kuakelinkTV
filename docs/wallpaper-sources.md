# Bundled launcher backgrounds

These photographs are bundled as the launcher's default backdrop, including on
fresh installs without external theme files. They rotate sequentially every five
minutes, with 40% dimming. External themes and the on-TV wallpaper choice still
take precedence. The images are 1920 × 1080 JPEGs, downloaded on 2026-11-04.
